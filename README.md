# Algoritmos e Lógica de Programação 💻

Este repositório reúne projetos acadêmicos e exercícios práticos desenvolvidos durante o curso de Ciência da Computação. O objetivo é documentar a evolução no entendimento de algoritmos fundamentais, estruturas de dados e boas práticas de codificação em C++.

## 📂 Índice de Projetos

| Projeto | Descrição | Tecnologias |
| :--- | :--- | :--- |
| **[Sistema de Biblioteca](./Sistema-Biblioteca)** | CRUD completo para gerenciamento de livros com validação de ISBN e ordenação (Bubble Sort). | C++ |
| **[Gestão de Vendas](./Sistema-Gestao-Vendas)** | PDV com controle de estoque, uso de **Structs** complexas e algoritmos de **Busca Recursiva**. | C++ |
| **[Processador de Arquivos](./Processador-Arquivo-Texto)** | Leitura de TXT, contagem de frequência com **Lista Encadeada** dinâmica e persistência em **Binário**. | C++ |

## 🛠️ Tecnologias e Conceitos Abordados

* **Linguagem:** C++
* **Conceitos Fundamentais:**
    * Manipulação de Arrays e Strings
    * Estruturas de Repetição e Condicionais
    * Modularização de Funções
* **Estruturas de Dados e Memória:**
    * **Structs** e Tipos Abstratos de Dados
    * **Ponteiros** e Alocação Dinâmica de Memória (`new`/`delete`)
    * **Listas Encadeadas** (Linked Lists)
* **Algoritmos Avançados:**
    * Métodos de Ordenação (Bubble Sort, Insertion Sort)
    * Recursividade
    * Manipulação de Arquivos de Texto (`fstream`) e Binários
